# rsfulmen v0.1.6 — file-backed catalogs, fulpack create, lockfile, host identity

**Release Date**: 2026-08-20

## Overview

Feature release after v0.1.5. rsfulmen can validate JSON against on-disk schema
trees, reports host binary identity for `version --extended`, commits
`Cargo.lock` for CI, and stops fulpack create from substituting unsupported
checksums. MSRV remains **1.88**. Embedded Crucible is **v0.4.19**.

## Key Changes

### File-backed schema catalogs

Additive APIs next to the existing embed-id validators. Check payloads against
on-disk schema trees with offline `$ref`. Traversal, symlink path components,
non-local `file:` hosts, unsupported URI schemes, and duplicate `$id`s fail at
compile time. On Unix, each path component is opened with `openat(2)` and
`O_NOFOLLOW`.

### Host binary identity

`rsfulmen::buildinfo` plus `host_identity!()` so `FULMEN_HOST_*` is evaluated
in the **application** crate. `resolve()` is a process-env fallback
(informational). Pins (rsfulmen + Crucible) are a labeled second block and
never become host `Commit:`. Invalid dirty stamps stay unknown.

### Fulpack create

Requesting sha512/sha1/md5 returns `INVALID_OPTIONS` instead of hashing
SHA-256 under another label. Gzip create always uses compression level 6;
`compression_level` is ignored for gzip (tar.gz and zip still honor it).

### Tooling and lockfile

- goneat pin **v0.5.16**
- `Cargo.lock` is committed; CI Test, Feature Matrix, and MSRV use `--locked`
- Working toolchain pinned to **1.98.0** for fmt/clippy; MSRV job stays 1.88

## Test Coverage

438 unit tests, 76 doc tests. `cargo test --locked --all-features`; clippy
`-D warnings` on 1.98.0; MSRV 1.88 locked tests.

## Requirements

- **Rust**: 1.88+ (MSRV, unchanged)
- **Crucible**: v0.4.19 (embedded)

## Migration Guide

Embed-id schema APIs are unchanged. New catalog APIs are additive.

Fulpack create callers that requested sha512, sha1, or md5 must pass sha256 or
xxh3-128 (or handle `INVALID_OPTIONS`).

Host identity requires the **application** `build.rs` to stamp `FULMEN_HOST_*`;
rsfulmen does not read the app's git at compile time of this crate.
