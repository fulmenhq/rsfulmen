# rsfulmen v0.1.0 Release Notes

**Release Date**: 2026-01-08
**Release Type**: Initial Release

## Overview

First release of rsfulmen, the Rust implementation of the Fulmen helper library ecosystem. Provides idiomatic Rust APIs for Crucible SSOT assets with compile-time embedding.

## Highlights

- **Config Module** – XDG Base Directory support with cross-platform paths
- **Three-Layer Config** – Embedded defaults → user overrides → runtime injection
- **Foundry Catalogs** – Country codes, HTTP statuses, exit codes, signals, MIME types, patterns
- **Schema Validation** – Offline validation with embedded meta-schemas (Draft 2020-12)
- **Error Handling** – Canonical error envelope with severity, correlation, and exit codes
- **Telemetry Metrics** – Counters, gauges, histograms with schema-valid JSON export
- **Crucible Shim** – Embedded access to docs, schemas, and config assets
- **Docscribe** – Documentation access with frontmatter parsing
- **Similarity** – Text similarity scoring with multiple algorithms

## Modules

### Config (`config`)

Configuration path utilities following the Fulmen Config Path Standard.

- XDG Base Directory compliance (Linux, macOS, Windows)
- Application-specific config/data/cache directories
- Fulmen ecosystem directory helpers
- Legacy config path fallback support

### Three-Layer Config (`config::three_layer`)

- Layer 1: Embedded Crucible defaults
- Layer 2: User overrides from config directory
- Layer 3: Runtime overrides via API
- Schema validation integration
- Null-deletes-key semantics

### Foundry (`foundry`)

Enterprise-grade foundation utilities from Crucible catalogs:

| Catalog         | Description                                          |
| --------------- | ---------------------------------------------------- |
| `country_codes` | ISO 3166-1 with triple-index (alpha2/alpha3/numeric) |
| `http_statuses` | HTTP status registry with grouping helpers           |
| `exit_codes`    | Standardized exit codes with categories              |
| `signals`       | Cross-platform signal catalog                        |
| `mime_types`    | Content-based detection + extension lookup           |
| `patterns`      | Regex, glob, literal from Crucible                   |

### Schema Validation (`schema_validation`)

- Offline validation using embedded meta-schemas
- Draft 2020-12 default, Draft-07 supported
- YAML schema support
- Crucible module schema resolver

### Error Handling (`error_handling`)

- Canonical error envelope extending Pathfinder schema
- Severity levels: Info, Low, Medium, High, Critical
- Correlation IDs and exit codes
- Schema-valid JSON serialization

### Telemetry Metrics (`telemetry_metrics`)

- Taxonomy-backed counters, gauges, histograms
- Schema-valid JSON event export
- Thread-safe metric recording

### Crucible (`crucible`)

- `metadata()` – Sync metadata (version, commit, synced_at)
- `version()` – Crucible version string
- Asset listing and retrieval APIs

### Docscribe (`docscribe`)

- Embedded doc retrieval via Crucible shim
- YAML frontmatter extraction

### Similarity (`similarity`)

- Levenshtein, Damerau-Levenshtein, Jaro-Winkler
- Normalized scoring (0.0 to 1.0)
- `did_you_mean` formatted suggestions
