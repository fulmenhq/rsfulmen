# rsfulmen v0.1.3 — Five new modules, closing gofulmen parity

**Release Date**: 2026-02-08

## Overview

Adds five feature-gated modules to close parity with gofulmen: app identity discovery, structured logging, canonical hashing, safe filesystem discovery, and terminal utilities. All modules follow Crucible schema conventions, use `#[cfg(feature)]` gates, and include comprehensive test coverage with devrev four-eyes audit.

## Key Changes

### New Modules

- **appidentity** — App identity discovery from `.fulmen/app.yaml` with upward directory search and `FULMEN_APP_IDENTITY_FILE` override. Supports YAML and JSON identity files with name validation.

- **logging** — Structured logging with SIMPLE (human-readable) and STRUCTURED (JSON) profiles. Leveled severity from Trace through Fatal, component context, and structured key-value fields. Thread-safe with configurable output writers.

- **fulhash** — Canonical hashing with xxHash3-128 (fast, default) and SHA-256 (cryptographic). Streaming support via `hash_reader()`. Digest format `algo:hex` matches gofulmen's `FormatDigest`. Strict canonical validation in `parse_digest()` rejects uppercase hex, empty hex, and wrong-length digests.

- **pathfinder** — Safe filesystem discovery with glob patterns. Crucible schema-aligned types (`FindQuery`, `FindResult`, `FindResults`, `PathMetadata`) with `#[serde(rename_all = "camelCase")]`. Symlink boundary enforcement, hidden file pruning via `filter_entry()`, warning collection for non-fatal errors, and SHA-256 checksums in `sha256:<hex>` format.

- **ascii** — Terminal utilities with grapheme-cluster-aware width calculation using `UnicodeWidthStr`. Box drawing, display width analysis, and safe truncation/padding that preserves grapheme boundaries.

### Feature Flags

| Feature       | Dependencies                        | Description                          |
| ------------- | ----------------------------------- | ------------------------------------ |
| `appidentity` | serde_json                          | App identity from `.fulmen/app.yaml` |
| `logging`     | serde_json                          | SIMPLE/STRUCTURED logging profiles   |
| `fulhash`     | xxhash-rust, sha2, hex              | xxh3-128 + SHA-256 hashing           |
| `pathfinder`  | walkdir, sha2, hex, glob            | Filesystem discovery with checksums  |
| `ascii`       | unicode-width, unicode-segmentation | Terminal + Unicode utilities         |

All features are included in `default` and `full` feature sets.
