# rsfulmen v0.2.1 — goneat v0.6.2, tagger env, deny licenses

**Release Date**: 2026-10-12

## Overview

Patch release after v0.2.0. Records the goneat v0.6.2 pin from #18, refreshes
`Cargo.lock` within current ranges, requires `RSFULMEN_TAGGER_NAME` /
`RSFULMEN_TAGGER_EMAIL` for signed tags, and adds `deny.toml` so
`cargo deny check` licenses passes. MSRV remains **1.88**. Embedded Crucible
is **v0.4.19**.

## Key Changes

### Estate-wide darwin/amd64 drop

goneat v0.6.2+ has no `darwin/amd64` asset. This is an estate-wide drop:
Intel macOS cannot install or bootstrap goneat from this pin (stay on
v0.6.1 there, or use a supported triple).

### Signed-tag identity

`make release-tag` and `make release-verify-tag` require
`RSFULMEN_TAGGER_NAME` and `RSFULMEN_TAGGER_EMAIL`. The annotated tag is
stamped with those values; verify compares the tag object against the same
env. No names, emails, or key fingerprints are committed.

### Tooling and crates

- goneat pin **v0.6.2** (#18)
- `Cargo.lock` refresh: xxhash-rust **0.8.19**, libc **0.2.190**,
  serde_json **1.0.154**
- Held: uuid **1.26.1** (1.28.0 needs rustc 1.89), jsonschema 0.17, dirs 5,
  thiserror 1, rstest 0.18, unicode-width 0.1, zip 2, sha2 0.10,
  signal-hook 0.3, base64 0.22
- `deny.toml` license allow list

## Test Coverage

`cargo fmt --all -- --check`; clippy `-D warnings` on 1.98.0;

`make prepush`. MSRV 1.88 locked build/test.

## Requirements

- **Rust**: 1.88+ (MSRV, unchanged)

## Migration Guide

No public API changes. Release operators must export
`RSFULMEN_TAGGER_NAME` and `RSFULMEN_TAGGER_EMAIL` before
`make release-tag` / `make release-verify-tag`.
