## Release Documentation Model

rsfulmen follows a three-tier release documentation model:

1. **[CHANGELOG.md](../../CHANGELOG.md)** – Complete history of all notable changes (Keep a Changelog format)
2. **[RELEASE_NOTES.md](../../RELEASE_NOTES.md)** – Detailed notes for the last 3 releases
3. **docs/releases/** – Archive of older release notes (this directory)

When a 4th release is published, the oldest release from RELEASE_NOTES.md is moved here.
