# rsfulmen v0.1.5 — branch/PR workflow, Crucible v0.4.13, dependency hygiene

**Release Date**: 2026-06-05

## Overview

A process and maintenance release. rsfulmen adopts a branch/PR development
workflow (replacing the original micro-team direct-push model), syncs Crucible
v0.4.13, and clears dependency and tooling tech debt. There are no new modules,
no public API changes, and no breaking changes.

## Key Changes

### Development workflow

- Moved from direct-push-to-`main` (micro-team) to a **branch/PR workflow**.
  Branch protection will be enabled after this release.
- Removed the **guardian browser-intercept** from the git hooks (commit and
  push). It is obsolete under branch-based review; hooks were regenerated
  guardian-free via `goneat hooks generate` (without `--with-guardian`).

### Crucible v0.4.13 sync

Synced from Crucible v0.4.12 to v0.4.13:

- `devlead` / `devrev` / `qa` role-prompt enrichment (contract-conformance
  checklists, cross-role notes; role version `v1.0.0` → `v1.0.1`)
- Upstream schema slimming (foundation, classifiers, ailink schemas)
- Mechanical YAML normalization delivered by upstream (2-space inline-comment
  convention)

`RolePrompt`'s forward-compatible deserialization absorbed the enriched role
fields with no Rust changes.

### Tooling

- **goneat** pinned `v0.5.1` → `v0.5.13`. v0.5.13 resolves a format
  check/apply engine divergence and an `ssot sync` metadata-indentation issue
  surfaced during this cycle (collaboration with the goneat team).
- Added **`.goneatignore`** to exclude the deliberately-malformed negative-test
  fixtures synced from Crucible from goneat assess (standard galaxy protocol,
  mirroring crucible's own `.goneatignore`).

### Dependencies

- Migrated off the deprecated/archived **`serde_yaml`** (dtolnay) to the
  maintained, API-compatible **`serde_yaml_ng`** `0.10`. Aliased via Cargo's
  `package =` rename, so all call sites compile unchanged.

  > Note: `Cargo.lock` is gitignored for this library, so in-semver minor
  > bumps are not versioned; downstream consumers resolve from `Cargo.toml`
  > requirements. Major/breaking bumps (`thiserror` 2, `dirs` 6,
  > `unicode-width` 0.2, `jsonschema` 0.3x) are deferred to a future release.

### Bug Fixes

- **Flaky `appidentity` test isolation**: `TestDir` temp directories could
  collide under parallel test threads (shared `{pid}-{nanos}` name), causing one
  test to read another's `.fulmen/app.yaml`. Fixed with an `AtomicU64` sequence
  counter in the temp-dir name (mirrors the v0.1.4 pathfinder fix).

## Test Coverage

362 unit tests, 74 doc tests. All quality gates pass (`make check-all`);
`goneat assess` (format, lint, security) reports 100% health.

## Requirements

- **Rust**: 1.88+ (MSRV, unchanged from v0.1.4)
- **Crucible**: v0.4.13 (embedded)

## Migration Guide

No breaking changes. No public API changes. Existing code compiles and runs
without modification. The `serde_yaml` → `serde_yaml_ng` swap is internal and
does not affect rsfulmen's public surface.
